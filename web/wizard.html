Welcome to MailPilot

Your inbox copilot: it watches your Gmail, drafts replies with Claude, and sends only what you approve. Setup takes about five minutes.

1 · How should MailPilot think?

Pick how drafts get written. You can change this later in Settings.

Use an Anthropic API key — simplest

Pay-as-you-go; a typical reply costs about a cent. Create a key at console.anthropic.com.

Use my Claude subscription

Uses the Claude Code app already installed and signed in on this computer — no separate billing.

Install Claude Code

Install it, sign in with your Claude account once, then hit “Check again”.

2 · Connect your Gmail

MailPilot signs in with an app password — a special 16-character password Google issues for one app. Your real password is never used or stored.

1. Turn on 2-Step Verification 2. Create app password

On the app-passwords page, name it “MailPilot” and copy the 16-character code it shows.
